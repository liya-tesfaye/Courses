# Todo App

A simple Todo List application built with **HTML, CSS, and JavaScript**. Users can add tasks, mark them as completed, and change their priority level. Each priority is represented by a different color to make tasks easy to identify.

## Features

- **Add Todos:** Enter a task and add it to the list.
- **Mark as Completed:** Click a task name to mark it as completed or undo its completion.
- **Change Priority:** Increase or decrease the priority of each task.
- **Color-Coded Priorities:** Tasks have three priority levels:
  - 🔵 Low Priority
  - 🟡 Medium Priority
  - 🔴 High Priority
- **Input Validation:** Prevents empty tasks from being added.
- **Keyboard Support:** Press Enter to add a task.
- **Responsive Design:** Layout adapts to smaller screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM manipulation and event listeners)

## How to Use

1. Enter a task in the input field.
2. Click **Add Todo** or press Enter.
3. Click the task name to mark it as completed.
4. Click **+ Priority** to increase its priority.
5. Click **- Priority** to decrease its priority.
6. The task's color changes according to its priority level.
